# 💻 IT Performance Analytics Dashboard

This project is developed as part of IBM Cognos Analytics Case Study.

## 📊 Project Overview
This repository contains 6 analytical projects focusing on IT performance, employee analysis, and business insights.

## 📁 Projects Included

### 🔹 Q1 - Project Health Report
- Budget vs Actual Cost
- Planned vs Actual Hours
- Cost Overrun %

### 🔹 Q2 - Attrition Report
- Employee attrition analysis
- Department & experience insights

### 🔹 Q3 - Billability Analysis
- Billable vs Non-billable hours
- Department-wise performance

### 🔹 Q4 - Exploration
- Attrition factors analysis
- Risk identification

### 🔹 Q5 - Dashboard
- KPI Metrics
- Charts & visual insights

### 🔹 Q6 - Story
- Business storytelling
- Strategic insights
