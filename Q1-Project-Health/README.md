📊 Q1 – Project Health Report

🎯 Objective
To analyze project performance by comparing:
- Budget vs Actual Cost  
- Planned Hours vs Actual Hours  
- Cost Overrun %

📈 Key Features
- Conditional formatting:
  - 🔴 Red → Overrun > 20%
  - 🟠 Amber → 10%–20%
  - 🟢 Green → < 10%
- Filters:
  - Client Country
  - Project Type

🛠 Tools Used
- IBM Cognos Analytics
