🎬 Q6 – IT Business Story

🎯 Objective
To present key insights and findings using a structured storytelling approach for better decision-making.

📖 Story Overview

🟢 Scene 1 – Introduction
Overview of IT company performance and objectives.

📊 Scene 2 – Project Health
Analysis of budget vs actual cost and project overruns.

📈 Scene 3 – Resource Utilization
Billability trends and employee efficiency insights.

📉 Scene 4 – Attrition Analysis
Understanding employee exit patterns and key factors.

💰 Scene 5 – Financial Insights
Revenue, cost distribution, and client impact.

🎯 Scene 6 – Strategic Recommendations
- Improve employee satisfaction to reduce attrition  
- Focus on high-value clients and technologies  
- Optimize resource utilization  
- Control project cost overruns  

🛠 Tools Used
- IBM Cognos Analytics (Story Feature)
