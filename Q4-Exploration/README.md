🔍 Q4 – Exploration Analysis

🎯 Objective
To explore and identify key factors contributing to:
- Employee Attrition
- Project Cost Overruns

📊 Key Insights

📉 Attrition Analysis
Top factors affecting attrition:
- Experience Band
- Performance Rating
- Department

💰 Project Overrun Analysis
Top factors for project overruns:
- Project Type (Fixed vs T&M)
- Budget vs Actual Cost
- Resource Utilization

📈 Key Findings
- Employees with certain experience levels show higher attrition
- High-performing employees leaving indicates potential issues
- Fixed projects are more likely to exceed budget

🛠 Tools Used
- IBM Cognos Analytics (Exploration)
